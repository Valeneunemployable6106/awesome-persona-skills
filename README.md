## 🛠️ Troubleshooting Common Issues

If you encounter difficulties, consult these common solutions:

*   Installation errors: Ensure your user account has administrative permissions. Try running the installer as an administrator by right-clicking the file and selecting Run as Administrator.
*   Program fails to start: Check that you have modern graphics drivers installed on your computer. 
*   Performance issues: If the software runs slowly, close other demanding applications, such as video editors or high-end games, while you engage with your personas.
*   Missing items: If your library appears empty, ensure you have an active internet connection to download the latest character data. Use the Refresh button in the settings menu to force an update.

## 📖 Managing Your Data

The software saves your progress automatically. All persona data resides in a local folder on your computer. To back up your work, copy the contents of the /data/ folder to an external hard drive or cloud storage service. 

If you decide to uninstall the software, navigate to your Windows Settings, go to Apps, and find the application in the list. Select Uninstall to remove the application files from your system. Note that deleting the application may remove your customized persona library unless you have saved a copy of your data elsewhere.
